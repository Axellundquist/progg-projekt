# progg-projekt

This project includes a shared set of generic packaging classes and example frontend/backend usage to keep selectors and model mappings synchronized.

- `shared/genericClasses.js` contains the canonical list of classes with labels and help text.
- `frontend/index.html` demonstrates a multi-select dropdown with chip display, sensible defaults, and tooltips sourced from the shared list.
- `backend/classMap.js` mirrors the same classes for backend/model logic by importing the shared definitions.
